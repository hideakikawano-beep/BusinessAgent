# ScreenKnowledge（仮称）

自分のPC作業を定期スクリーンショットで記録し、AI（Claude API）で解析して、**オペレーションマニュアル・ナレッジ・日次作業ログを自動構築する**ローカルツール。生成物はすべて自分のPC内に保存され、ブラウザの検索画面からいつでも取り出せる。

> **現在のステータス: 設計完了・実装前。** このディレクトリには設計ドキュメントとコード雛形のみが入っており、実装はフェーズ単位でClaude Code（Opus等）に依頼して進める。進め方は下記「開発の進め方」を参照。

## できるようになること

- **常時自動キャプチャ**: 30秒ごと＋ウィンドウ切替時にスクリーンショットを取得（重複除去・除外アプリ・一時停止つき）
- **マニュアル自動生成**: 「今の作業をマニュアル化」とマークした作業は、ステップごとのスクリーンショット付き手順書（Markdown）になる。同じ作業を繰り返すとマニュアルが更新される（重複作成しない）
- **日次作業ログ**: 「今日何をしたか」が毎日Markdownで自動生成される（日報の下書きにも使える）
- **ナレッジノート**: 作業中の気づき・学びが自動で蓄積される
- **検索・閲覧**: ブラウザで開くローカル検索画面（日本語全文検索・日別タイムライン・マニュアル閲覧）

## しくみ（概要）

```
[キャプチャデーモン] --30秒毎+ウィンドウ切替--> スクリーンショット + メタデータ (PC内に保存)
        ↓ 夜間バッチ（Claude API・50%割引）/ マーク作業は即時解析
[セッション化 + AI解析] --> 「何のアプリで何をしていたか」の構造化データ
        ↓
[ナレッジビルダー] --> vault/manuals/  操作マニュアル（スクショ付き・更新型）
                      vault/knowledge/ ナレッジノート
                      vault/daily/     日次作業ログ
        ↓
[検索UI] --> http://127.0.0.1:8756 （PC内のみ・外部公開なし）
```

- データ保存先: `~/ScreenKnowledge/`（このリポジトリの外・PC内のみ）
- 外部送信されるのは**解析用にダウンスケールした画像とメタデータのみ**（Claude APIへ）。除外アプリ・保持期間・月次予算上限で統制する
- 費用目安: 月 $10〜25 程度（使い方次第・要確認）。既定で月$25の上限を設定済み

## 開発の進め方（Opusでのフェーズ実装）

各フェーズは自己完結しており、新しいClaude Codeセッションで以下のように依頼するだけで実装が進む:

| 順番 | 依頼文の例 | 完了すると |
|---|---|---|
| 1 | 「screen-knowledge の Phase 1 を docs/10-phase1-capture.md に従って実装して」 | 安全に記録できる（キャプチャ+トレイ+除外+自動削除） |
| 2 | 「screen-knowledge の Phase 2 を docs/11-phase2-analyze.md に従って実装して」 | 日次作業ログが毎朝手に入る |
| 3 | 「screen-knowledge の Phase 3 を docs/12-phase3-knowledge.md に従って実装して」 | スクショ付きマニュアルが自動生成される |
| 4 | 「screen-knowledge の Phase 4 を docs/13-phase4-viewer.md に従って実装して」 | ブラウザで検索・閲覧できる |
| 5 | 「screen-knowledge の Phase 5 を docs/14-phase5-integrations.md に従って実装して」 | （任意）Notion同期・Slack日報など |

各フェーズ完了時点でツールとして使える状態になるため、Phase 2まで実装して運用しながら残りを進める形でもよい。

## 注意事項

- スクリーンショットには顧客情報・社内機密が写り込む前提で設計されているが、**導入前に社内のセキュリティポリシーとの整合を必ず確認すること**（docs/01の冒頭チェックリスト）
