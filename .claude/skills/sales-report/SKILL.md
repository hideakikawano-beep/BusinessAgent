# 営業成績レポート作成（HubSpotデータ）

四半期・月次の営業成績レポートを以下の手順で作成する。レポートの所見・打ち手の部分は sales-director エージェントの視点で書く。

## 1. データ取得

1. HubSpot MCPツール（`mcp__HubSpot__*`）が利用可能か ToolSearch で確認する。なければ環境変数 `HUBSPOT_ACCESS_TOKEN` を確認し、REST API（`POST /crm/v3/objects/deals/search`）を使う。どちらもなければ接続手順を案内して停止する
2. まず1件だけ取得して認証とプロパティ構成（パイプライン定義、通貨、カスタムプロパティ）を確認してから本取得に進む
3. 対象期間について以下を取得する:
   - 受注案件: dealstage = Closed Won（納品日3フィールドと closedate、取引タイプ、amount、hubspot_owner_id を含める）
   - 失注案件: dealstage = Closed Lost かつ closedate が期間内（勝率算出用）
   - オープン案件: close date が期間内のパイプライン残（着地見込み用）
   - 各Dealの hubspot_owner_id をOwner名に解決する

## 2. 集計定義（2026年Q2に確立した標準ルール）

- **対象**: Closed Won かつ **取引タイプ＝新規MRR**
- **計上基準（納品日ベース）**: 「納品日」「SW納品日」「HW納品日」の**3フィールドを横断**し、いずれかが期間内に入る商談を1件として計上する。複数フィールドが期間内に入る商談は**重複控除**し、**最も早い納品日**の月に帰属させる
- **参考値**: 受注日（closedate）ベースの金額・件数も併記し、納品リードタイムによる差異（前期受注分の流入・当期受注分の翌期繰越）を説明する
- 勝率 = Won件数 / (Won件数 + Lost件数)、平均単価 = 受注金額 / 受注件数
- 着地見込み = 受注実績 + オープン案件の金額 × フェーズ別確度
- 集計は取得データのみから算出し、推測で数字を補わない。通貨混在や定義が曖昧な場合は「確認事項」として明記する

### 納品日フィールドの注意（要確認）

2026年6月時点で納品日フィールドは移行過渡期にあった（旧「納品日 nouhinbi（利用停止ラベル）」→「SW納品日 / HW納品日」。新フィールド delivery_date__c は未使用）。**単一フィールドでの集計は大きな漏れを生む**。集計前に営業企画へ正フィールドの最新運用を確認し、確認できない場合は3フィールド横断・重複控除方式を使い、その旨をレポートに明記する。

## 3. レポート構成（`reports/YYYY-QN-sales-report.md`）

1. サマリー: 計上金額・件数・勝率・平均単価（納品日ベース）。受注日ベースを参考併記。期間途中の場合はQTDである旨と、納品予定日の先行入力により月末確報で増える可能性を明記
2. 集計方法の定義（対象・計上基準・重複控除・データ取得時点）
3. 月次推移と読み方（納品ベースと受注ベースの形状差の説明）
4. フェーズ別パイプライン残と着地見込み
5. 担当者別成績テーブル（計上額・件数・平均単価）
6. 主要案件リスト（金額上位の受注・進行中案件）
7. 営業責任者としての所見（リスク・残期間の打ち手）

## 4. 提出前チェック

- 整合チェック: 担当者別合計 = 月次合計 = 全体合計、件数の突合を確認してから提出する
- レポートには**実際の顧客・担当者・金額データ**が含まれる。リモートへpushする前に、リポジトリに含めてよいかユーザーに確認する
