# 90. 手動検証チェックリスト（OS別）

自動テストで検証できない項目（OS権限・トレイ・マルチモニタ・実API）の実機確認手順。各フェーズの受入基準と対応する。

## Phase 1: キャプチャ基盤

### 共通
- [ ] `uv sync` がクリーンな環境で完了する（コンパイラ不要・wheelのみ）
- [ ] `sk start` でトレイ/メニューバーにアイコンが出る
- [ ] 通常作業10分で `sk status` の記録数が増える（メタ行 ≥ 1行/45秒）
- [ ] 同じ文書で連続タイピング30秒 → メタ行は毎tick、画像保存は≤3枚
- [ ] ウィンドウ切替直後のtickで必ず画像が保存される
- [ ] 除外アプリ（1Password等）を前面にする → `skipped_reason='excluded'`、shots/に画像が増えない
- [ ] トレイ「一時停止(15分)」→ 次tickから記録が止まる。「再開」で復帰
- [ ] トレイ「今の作業をマニュアル化 開始」→ marksに行が入り、キャプチャ間隔が5秒になる。「終了」で戻る
- [ ] 5分間放置（アイドル）→ 記録が止まる。キー入力で再開
- [ ] `sk purge --dry-run` が削除対象を正しく列挙する（テスト用に retention を短くして確認）
- [ ] `sk backup` がsqliteバックアップ＋vault zipを生成する
- [ ] `sk autostart enable` → 再ログオンでデーモンが自動起動する
- [ ] logs/daemon.log がローテーションする
- [ ] APIキーが未設定でもP1機能はすべて動く

### Windows
- [ ] 混在DPI（例: 4K 150% + FHD 100%）の両モニタで、アクティブウィンドウのあるモニタが正しいサイズ・非ぼやけで撮影される
- [ ] ホットキー `Ctrl+Alt+M` でマークがトグルする（管理者権限不要）

### macOS
- [ ] 画面収録権限**なし**で `sk doctor` → 「missing_screen_recording」を検知して手順を案内する（誤って ok と言わない）
- [ ] 権限付与後、ウィンドウタイトルが取得できている（framesのwindow_titleが空でない）
- [ ] Retinaで保存画像の長辺が `store_long_edge_px` 以下
- [ ] メニューバーの各メニュー項目が動作する（rumps）

### 24時間ソーク（P1完了判定）
- [ ] 1営業日つけっぱなしでクラッシュ・メモリ肥大（>300MB）・ディスク暴走がない
- [ ] スリープ→復帰後も記録が再開する

## Phase 2: 解析・日次ログ

- [ ] `scripts/smoke_analyze.py` が実APIで1セッションを解析し、$0.05未満で `api_usage` に実トークン数が記録される
- [ ] 1日運用後の朝、`vault/daily/昨日.md` が生成され、実際の作業と大きく乖離しない
- [ ] `sk status` に今月のAPIコストが表示され、Anthropicコンソールの請求とオーダーが一致する
- [ ] `budget.monthly_usd` を一時的に極小値にする → 解析が止まり、トレイに上限到達表示。キャプチャは継続
- [ ] 夜間PCをスリープ → 翌朝起動時にキャッチアップが走り、未解析分が処理される

## Phase 3: マニュアル生成

- [ ] マークして実作業（例: HubSpotで商談更新）→ 終了後数分でスクショ付きマニュアルが生成される
- [ ] 同じ作業をもう一度マークして実行 → 新規ファイルが増えず、同じマニュアルの revision が上がり、旧版が .history/ に残る
- [ ] マニュアル内の画像リンクがVS Code / Obsidian / GitHubプレビューで表示される
- [ ] purge実行後もマニュアルの画像（vault/manuals/assets/）は消えない
- [ ] （Windows）ホットキーでマーク→マニュアル生成の一連が動く

## Phase 4: 検索UI

- [ ] `sk serve` → http://127.0.0.1:8756 が開く。LAN内の他端末からはアクセスできない
- [ ] 「請求書」で検索 → 「請求書発行」を含むマニュアルがヒットし、スニペットがハイライトされる（trigram要件）
- [ ] 日別タイムラインにセッションとサムネイルが表示され、purge済みフレームは壊れた画像にならない
- [ ] デーモン稼働中（書き込み中）に5分間ビューアを操作してもエラーが出ない
- [ ] `sk search "キーワード"` がWeb UIと同じ上位結果を返す

## Phase 5: 連携

- [ ] `sk notion sync` 2回目の実行が「変更0件」になる（冪等）
- [ ] Slack日報が4000字以内で投稿され、失敗時3回リトライ後もデーモンが生きている
- [ ] 連携を無効化した状態で該当モジュールのimport・外部通信が発生しない
