# BusinessAgent

NottaのBtoB営業を推進するための、役割別AIエージェント環境です。Claude Codeのカスタムサブエージェント機能を使い、経営・営業・法務・技術の各役割のエージェントと協働できます。

## エージェント一覧

| エージェント | 役割 | 主な相談内容 |
|---|---|---|
| `marketing-director` | マーケティングダイレクター | リード獲得施策、ABM、コンテンツ企画、競合ポジショニング |
| `sales-director` | 営業責任者 | 営業戦略、商談戦略、提案書・見積もりレビュー、価格交渉 |
| `coo` | COO | 事業計画、部門間の優先順位調整、価格戦略、KPI設計 |
| `legal` | 法務 | 契約レビュー（NDA・利用契約）、個人情報保護、広告表現チェック |
| `cto` | CTO | セキュリティチェックシート対応、技術的なRFP回答、連携・SSO等の技術要件 |

エージェント定義は [`.claude/agents/`](.claude/agents/) にあります。

## 使い方

このリポジトリでClaude Codeを起動し、普通に日本語で依頼するだけです。内容に応じて適切なエージェントが自動的に起動します。

```
このNDAのドラフトをレビューして          → legal が対応
A社向けの提案書の構成を考えて            → sales-director が対応
来期のリード獲得施策を3つ提案して        → marketing-director が対応
```

特定のエージェントを名指しすることもできます。

```
cto として、このセキュリティチェックシートの回答案を作って
coo の視点で、この値引き要求を受けるべきか判断して
```

複数の役割の意見が欲しい場合は、並行して聞くこともできます。

```
この代理店契約の件、legal と coo それぞれの意見をまとめて
```

## 営業成績レポート（HubSpot連携）

`sales-director` はHubSpotのデータから四半期・月次の営業成績レポートを作成できます（手順はエージェント定義に組み込み済み）。レポートは `reports/` 配下にMarkdownで保存されます。

利用にはHubSpotへの接続が必要です。いずれかを設定してください。

1. **HubSpot MCPコネクタ**（推奨）: claude.ai の「設定 > コネクタ」でHubSpot公式コネクタを接続
2. **プライベートアプリトークン**: Claude Codeの環境設定で環境変数 `HUBSPOT_ACCESS_TOKEN` を登録（HubSpotの「設定 > 連携 > プライベートアプリ」で発行。Deals・Ownersの読み取りスコープが必要）

```
Q2の営業成績をHubSpotのデータから報告して   → sales-director がレポートを生成
```

## PC作業の自動ナレッジ化ツール（screen-knowledge）

[`screen-knowledge/`](screen-knowledge/) に、PC作業のスクリーンショットからオペレーションマニュアル・ナレッジ・日次作業ログを自動構築するローカルツールの設計ドキュメントと開発環境があります。開発はフェーズ単位でClaude Code（Opus等）に依頼する構成です。概要と進め方は [screen-knowledge/README.md](screen-knowledge/README.md) を参照してください。

## エージェントのカスタマイズ

各エージェントの知識や行動原則は `.claude/agents/` 配下のMarkdownファイルを編集することで調整できます。実際の商談や社内ルールに合わせて、以下のような情報を追記していくと精度が上がります。

- 最新の料金プラン・機能リスト
- 実際の競合比較資料・勝ちパターン
- 社内の値引きポリシー・契約ひな形の方針
- セキュリティチェックシートの過去回答集

## 注意事項

- `legal` の出力は正式な法律意見ではありません。重要な契約は必ず弁護士・正式な法務プロセスで確認してください。
- `cto` は製品仕様を創作しないよう設計していますが、顧客提出前に必ず実際の仕様を確認してください。
