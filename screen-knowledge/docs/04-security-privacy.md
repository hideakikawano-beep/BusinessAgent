# 04. セキュリティ・プライバシー

業務PCの画面を常時記録するツールであり、**顧客情報・社内機密が写り込むことを前提**に統制を設計する。

## データの所在と流れ

| データ | 保存場所 | 外部送信 | 保持期間 |
|---|---|---|---|
| 生スクリーンショット（WebP） | `~/ScreenKnowledge/shots/`（PC内のみ） | されない | 既定30日で自動削除 |
| フレームメタデータ（アプリ名・ウィンドウタイトル・時刻） | SQLite（PC内） | 解析時にタイトル列のみ送信 | 既定180日 |
| 解析用キーフレーム | — | **Claude APIへ送信**（1024pxに縮小、セッションあたり≤12枚） | API側ポリシーに従う（下記） |
| セッション解析結果・生成物（Markdown） | SQLite / `vault/`（PC内） | されない（Phase 5のNotion同期を明示的に有効化した場合を除く） | 無期限（ユーザー管理） |
| APIキー | OSキーチェーン（Windows資格情報マネージャー / macOSキーチェーン） | — | — |

## 外部送信されるデータの明細（Claude API）

1リクエストに含まれるもの:

- セッションのキーフレーム画像（最大12枚、長辺1024pxに縮小済み）
- セッションのメタデータ: アプリ名、ウィンドウタイトルの時系列、時刻
- システムプロンプト（解析指示。ユーザーデータを含まない固定文）

**Anthropic APIのデータ取扱い**: 商用APIの入力・出力は既定でモデル学習に使用されないとされる（要確認）。導入前に最新の [Anthropic Commercial Terms / Privacy Policy] を確認し、必要なら社内法務・セキュリティのレビューを受けること。データ保持期間・リージョンの要件がある場合も同様。

## 統制の一覧（多層防御）

| レイヤ | 統制 | 実装 |
|---|---|---|
| 撮影しない | 除外アプリ・タイトルキーワード（パスワードマネージャ等は既定で除外） | P1 `exclude.*`。該当tickはメタ行のみ・画像なし |
| 撮影しない | 一時停止（15分/1時間/今日中/無期限）・アイドル時自動停止 | P1 トレイメニュー |
| 送信しない | 解析時にも除外リストを再チェック（設定変更の遡及適用） | P2 keyframe選定時に `exclude` を再評価し、該当フレームを解析から除外 |
| 送信を減らす | 送信前1024pxダウンスケール・キーフレーム上限12枚 | P2 |
| 漏らさない | ビューアは127.0.0.1バインドのみ（`allow_lan`明示時を除く）・認証なしを明記 | P4 |
| 残さない | 生スクショ30日自動削除・ディスク上限10GB（古い順削除）。マニュアル採用画像はvaultへコピーされ削除対象外 | P1 purge |
| 秘匿する | APIキーはOSキーチェーン。ログ・生成物・例外メッセージにキーを出さない | P1 |
| 使いすぎない | 月次予算ハードストップ＋80%警告＋Anthropicコンソール側Spend Limit設定の案内 | P2 BudgetGuard |

## 導入形態の選択肢（社内確認の結果に応じて）

| 形態 | 設定 | 説明 |
|---|---|---|
| フル運用（既定） | そのまま | 常時キャプチャ＋夜間バッチ解析 |
| 手動記録のみ | `capture.interval_seconds: 0`（=常時キャプチャ無効。マーク中のみ記録） | 「マニュアル化したい作業」だけ明示的に記録・解析。外部送信も自分で選んだ作業のみ |
| ローカル記録のみ | APIキーを設定しない | 記録・タイムラインのみでAI解析なし（マニュアル自動生成は不可） |

> 実装メモ（P1）: `interval_seconds: 0` を「常時キャプチャ無効・マーク中のみtick」として解釈すること。

## 残存リスク（ユーザーに明示するもの）

- ローカルディスクが暗号化されていない場合、PC盗難時にスクショが読まれ得る → OSのディスク暗号化（BitLocker / FileVault）有効化を前提とする
- 除外リストは前方一致・キーワードベースであり完全ではない。写ってはいけない画面を開く前は一時停止を使う運用を案内する
- 生成マニュアルには画面上の実データ（顧客名等）が転記され得る → 共有前の人手確認を必須とする（全生成物にフッターで明示）
